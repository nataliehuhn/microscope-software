# Gridviewer #

This repository contains the GridViewer, a tool of the FabryMicroscopeSuite which allows to easily view the results of measurements and stitch grids.

### How to install ###

Download the repository and and execute the install.bat in the main folder. This will call:

	pip install -e .

which installs the gridviewer package and registers the command line calls `gridviewer` and `gridviewer_noconsole`. You can now open .tif files with the `GridViewerStart.bat` file in the main folder.
