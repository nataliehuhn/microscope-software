# Microscope software source archive — 2026-10-28

This tag preserves separately named source snapshots imported for Mic2 and Mic3.
Browse `sources/` for original code and `manifests/` for per-file SHA-256 hashes.
Git source blobs preserve the original bytes and match the manifests. For an
exact file export, use `git archive` or GitHub's archive download. Historical
nested `.gitattributes` files can affect line endings in an ordinary checkout.
The `archive-inventory.json` ZIP hashes refer to local backup files, not GitHub ZIP exports.

The maintained software lives on the `mic2` and `mic3` branches. This tag is
reference material and does not constitute an independently validated installation.
Source selection excludes generated data, caches, binary drivers/installers and
repository metadata. Mic3 manifests also enumerate the files retained only in
its full local ZIPs; Mic2 manifests enumerate its selected source files only.

Original directories and local backup ZIPs have been preserved. See
`docs/archives.md` on either maintained branch for locations and recovery steps.
